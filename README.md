# Cloud Color — support and privacy website

The public website for **Cloud Color**, a cozy paint-by-number app for iPhone and iPad: Support, Privacy Policy and Terms of Use.

A plain static site served by GitHub Pages: no build step, no cookies, no analytics, no third-party scripts. The contact form on the Support page sends messages through Formspree.

| Page | File |
|---|---|
| Home | `index.html` |
| Support (FAQ, billing help, problem reports, contact form) | `support/index.html` |
| Privacy Policy | `privacy/index.html` |
| Terms of Use (Apple's standard EULA + subscription terms) | `terms/index.html` |
